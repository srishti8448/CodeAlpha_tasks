
# C++ SGPA Calculator & Login Registration System

## 📌 About the Project

This project contains two simple C++ programs designed to practice basic programming concepts and file handling.

### 1. 🎓 SGPA Calculator

The SGPA Calculator:

* Takes the number of courses
* Takes grades and credit hours
* Calculates total credits
* Calculates total grade points
* Calculates the final SGPA

### 2. 🔐 Login & Registration System

The Login and Registration System:

* Allows users to create an account
* Takes username and password
* Checks for duplicate usernames
* Allows registered users to log in
* Stores user credentials using file handling

## 🛠️ Technologies Used

* C++
* File Handling
* Functions
* Conditional Statements
* Loops
